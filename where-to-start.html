מאיפה מתחילים?

מתחילים מלהכיר את המשרות והתפקידים שיש בתחום, אילו מילות מפתח חייבים להיות לכם בקורות חיים, את החברות הכי מובילות וגם שכר ראשוני!

משרות ותפקידים ←

מילון משרות ותפקידים שיש בשוק

אנחנו בטוחים שנתקלתם במשרות שאין לכם מושג מה הן אומרות או למי הן מיועדות... לכן בנינו את מילון המשרות :)

מעצב/ת למידה

מתכננים חוויות למידה דיגיטליות בצורה מעניינת, ברורה ואפקטיבית.

מפתח/ת הדרכה

בונים תכני הדרכה, מצגות, קורסים וחומרי למידה לעובדים או לסטודנטים.

מפתח/ת לומדות

מפתחים לומדות אינטראקטיביות באמצעות כלים דיגיטליים כמו Storyline או Rise.

רכז/ת למידה דיגיטלית

מנהלים מערכות למידה דיגיטליות, מעלים תכנים ועוקבים אחרי תהליכי למידה בארגון.

מטמיע/ת מערכות למידה

מלמדים עובדים להשתמש במערכות חדשות ומסייעים בהטמעה שלהן בארגון.

כותב/ת תוכן לימודי

כותבים תכנים מקצועיים לקורסים, הדרכות ולומדות דיגיטליות.

מומחה/ית LMS

אחראים על ניהול ותפעול מערכות למידה כמו Moodle או Canvas.

מאפיין/ת מוצר (Product Designer)

אחראים על חוויית המשתמש והמראה של המוצר הדיגיטלי — מאפיון המסכים ועד העיצוב הסופי, תוך חשיבה על צרכי המשתמש והמטרות העסקיות.

מעצב/ת UX

חוקרים ומתכננים את חוויית המשתמש במוצר כדי להפוך אותה לנוחה, ברורה ואינטואיטיבית יותר.

מעצב/ת UI

אחראים על העיצוב הוויזואלי של הממשק — צבעים, כפתורים, טיפוגרפיה, אייקונים ושפה גרפית.

UX Writer

כותבים את הטקסטים שמופיעים בממשק — הודעות, כפתורים, שגיאות והנחיות למשתמש.

חוקר/ת UX

מבצעים מחקרי משתמשים, ראיונות ובדיקות שימושיות כדי להבין איך אנשים משתמשים במוצר.

מאפיין/ת אינטראקציה

מתכננים איך המשתמש זז ופועל בתוך המערכת — אנימציות, מעברים והתנהגות המסכים.

מעצב/ת גרפי לדיגיטל

יוצרים חומרים גרפיים למוצרים דיגיטליים, רשתות חברתיות, אתרים וקמפיינים.

Front-End Developer

מפתחים את הצד שהמשתמש רואה באתר או באפליקציה — מסכים, כפתורים ואינטראקציות.

Back-End Developer

אחראים על הצד הטכנולוגי שמאחורי הקלעים — שרתים, בסיסי נתונים ולוגיקה של המערכת.

Full Stack Developer

משלבים עבודה גם על ה־Front-End וגם על ה־Back-End.

Web Developer

מפתחים ובונים אתרים ומערכות אינטרנט.

JavaScript Developer

מתמחים בפיתוח באמצעות JavaScript ובבניית אינטראקציות דינמיות באתר.

WordPress Developer

בונים ומעצבים אתרי WordPress ולעיתים גם מפתחים תוספים ותבניות.

QA Tester

בודקים מערכות ואתרים כדי למצוא באגים ולוודא שהמוצר עובד בצורה תקינה.

Technical Support

נותנים תמיכה טכנית למשתמשים ועוזרים בפתרון תקלות במערכות דיגיטליות.

מילות מפתח לקורות חיים

למדו איך לנסח בצורה מקצועית את הכישורים שלכם כדי לעבור מערכות סינון (ATS) ולבלוט בעיני מגייסים. לחצו על הכרטיסיות כדי לראות את ההמלצות.
