# מדריך להצגת פרויקט: "ללכת בטל״ם"

מסמך זה מרכז את כל המידע הארכיטקטוני, המבני והעיצובי של האתר. הוא נועד לעזור להציג את האתר בבחינה/פרזנטציה, להסביר כיצד הוא בנוי, באילו אלמנטים וטכנולוגיות השתמשנו, ואילו פתרונות ייחודיים שולבו בו.

המסמך מנוסח כך שבכל חלק מופיע תחילה ההסבר המלא בעברית, ורק לאחר מכן מרוכזים כל פרטי הקוד, שמות המחלקות (Classes) וקטעי ה-CSS הרלוונטיים, על מנת למנוע ערבוב של עברית ואנגלית באותה השורה.

---

## 1. מערכת העיצוב הגלובלית (Global CSS & Variables)

### הסבר בעברית

האתר מעוצב בסגנון ניאו-ברוטליזם. זהו טרנד עיצובי מודרני המאופיין בצבעי בסיס עזים ובוהקים, גבולות שחורים עבים במיוחד סביב כל האלמנטים, וצלליות שטוחות וקשיחות ללא טשטוש (בניגוד לצלליות רכות באתרים סטנדרטיים). סגנון זה מעניק לאתר מראה צעיר, נועז וייחודי המתאים לסטודנטים.

כדי לשמור על עקביות בכל האתר, הגדרנו מערכת של משתנים גלובליים ב-CSS. המערכת כוללת צבעים קבועים (כמו ירוק זרחני לפריטים פעילים, כחול מותאם, ורוד ברוטליסטי עז, שחור כהה לגבולות וטקסט, ולבן נקי לרקע כרטיסיות). כמו כן, הגדרנו באמצעות משתנים אלו את עובי הגבול השחור הקבוע, את היסט הצלליות הקשיחות (צללית קטנה של 4 פיקסלים וצללית בינונית של 8 פיקסלים) ואת מהירות מעברי האנימציה באתר.

### שמות מחלקות ופרטים טכניים

**מיקום המשתנים ב-CSS:**
הגדרות המשתנים נמצאות בבלוק ה-`:root` בקובץ `css/styles.css`.

**רשימת הצבעים והערכים הטכניים:**

- `var(--color-primary)` - ירוק זרחני (#2effb7)
- `var(--color-secondary)` - כחול מותאם (#4d7cff)
- `var(--color-pink)` - ורוד ברוטליסטי (#ff70e2)
- `var(--color-ink)` - שחור לגבולות וטקסט (#121212)
- `var(--color-surface)` - רקע לבן של כרטיסיות (#ffffff)
- `var(--color-bg)` - רקע האתר אפור בהיר (#fbfbfd)
- `--shadow-sm` - צללית קשיחה קטנה: `4px 4px 0 var(--color-ink)`
- `--shadow-md` - צללית קשיחה בינונית: `8px 8px 0 var(--color-ink)`
- `--transition` - מהירות מעברים: `0.2s ease`
- גבול ברירת מחדל: `border: 2px solid var(--color-ink)`

## 2. מבנה וניתוח העמודים (Page-by-Page Analysis)

### א. עמוד הבית (index.html)

#### הסבר בעברית

דף הבית נועד לייצר רושם ראשוני חזק ולהציג בצורה סיפורית למה חיפוש עבודה מוקדם במהלך התואר הוא קריטי.

הדף מורכב מכותרת עליונה בולטת וממורכזת. מתחתיה מופיע סקשן קומיקס אינטראקטיבי המציג בארבעה שלבים את סיפורה של סטודנטית שמסיימת תואר ומגלה שכולם דורשים ניסיון.

סקשן זה הונגש באופן מלא למקלדת ולקוראי מסך: לכל אחת מארבע כרטיסיות הקומיקס הוספנו מאפיינים המאפשרים למשתמשי מקלדת לעבור ביניהן בעזרת מקש ה-Tab. כאשר כרטיסיית קומיקס מקבלת פוקוס מקלדת, היא גדלה מעט ועולה למעלה, ומקבלת את אפקט הצללית הכחולה הזוהרת של האתר (בדיוק כמו בריחוף עכבר). הגדרנו מסגרת פוקוס כחולה מעוגלת פינות המתאימה בדיוק לצורת הכרטיס המקורית. קוראי מסך יקריאו את התיאור הנגיש של כל שלב ואת הטקסט בבועות הדיבור.

בתחתית הדף מופיעה קרוסלת ציטוטים המציגה חוויות של סטודנטים. קוד ה-JavaScript מחליף את הציטוטים בצורה דינמית בלחיצה על כפתורי החצים. כפתורי החצים קיבלו עיצוב ניאו-ברוטליסטי המשנה את הרקע שלהם לירוק בריחוף, אך שומר על צבע החצים שחור כדי למנוע היעלמות שלהם על הרקע הבהיר.

#### שמות מחלקות ופרטים טכניים

- **כותרת ראשית (Hero):** המחלקה `.hero.hero-centered` ומשתנה הגופן לכותרות `var(--text-page-title)`.
- **גריד הקומיקס:** המחלקה `.scenario-grid` המשתמשת ב-CSS Grid עם הגדרה רספונסיבית של `grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))`.
- **כרטיסיית קומיקס:** המחלקה `.feature-card` ובועות הדיבור שלה `.speech-bubble`.
- **מאפייני נגישות בקומיקס:** הוספת `tabindex="0"` וכן `aria-label` מותאמים אישית לכל כרטיסייה (לדוגמה `aria-label="קומיקס שלב 1: סיום התואר"`).
- **אנימציית ריחוף ופוקוס ב-CSS:**
  ```css
  .scenario-grid .feature-card:hover,
  .scenario-grid .feature-card:focus-visible {
    transform: translateY(-6px) scale(1.01);
    box-shadow: var(--color-blue) 0 8px 24px;
  }
  .scenario-grid .feature-card:focus-visible {
    outline: 4px solid var(--color-blue);
    outline-offset: 4px;
    border-radius: 16px;
  }
  ```
- **כפתורי הקרוסלה:** המחלקות `.carousel-container` ו-`.carousel-btn`.

### ב. עמוד "מאיפה מתחילים?" (where-to-start.html)

#### הסבר בעברית

עמוד זה משמש ככלי מעשי לסטודנטים וכולל מחשבון שכר אינטראקטיבי וכן גלריית לוגואים של חברות המעסיקות בוגרים.

מחשבון השכר מחולק בצורה מאוזנת לשתי עמודות במסכים רחבים: מימין טופס הזנת הנתונים (שבו כפתורי הבחירה מעוצבים ככרטיסים רחבים המקבלים רקע ירוק זוהר בריחוף/בחירה) ומשמאל אזור תצוגת התוצאות. שתי העמודות מופרדות באמצעות קו מפריד אנכי שחור ברוחב 2 פיקסלים. במסכים קטנים (מובייל), שאילתת המדיה משנה את הקו המפריד לאנכי/אופקי בהתאמה ומסדרת את החצאים זה מתחת לזה בצורה טבעית. תוצאת השכר מעוצבת בצורה בולטת במיוחד על גבי רקע ורוד עז עם גבול שחור עבה וצללית בולטת. לחיצה על כפתור "איפוס בחירה" מאפסת את בחירות המשתמש ומחזירה את תיבת התוצאות למצב ההוראות ההתחלתי.

קרוסלת החברות נעה באופן רציף ואוטומטי ימינה ושמאלה באמצעות אנימציית CSS אינסופית. כדי לאפשר נגישות מלאה, הוספנו כפתור עצירה/הפעלה נגיש המאפשר למשתמש לעצור לחלוטין את התנועה (שימושי מאוד לבעלי הפרעות קשב וריכוז או משתמשי קוראי מסך). הכפתור משנה את מצבו הוויזואלי (מעבר בין סימן עצירה לסימן נגינה) ואת הגדרות הנגישות שלו בזמן אמת.

#### שמות מחלקות ופרטים טכניים

- **תיבת המחשבון הכללית:** המחלקה `.calculator-box` והטופס הפנימי `.calculator-form`.
- **אפשרויות הבחירה (הרדיו):** המחלקה `.calculator-options label`.
- **כפתורי הפעולה:** המחלקה הגמישה המאגדת את הכפתורים `.calculator-actions` וכפתור האיפוס `#btn-reset`.
- **אזור התוצאות:** המחלקה `.calculator-results` ומכלול השכר המודגש `.salary-highlight`.
- **הקו המפריד ב-CSS:**
  ```css
  /* בדסקטופ - קו אנכי מימין לאזור התוצאות */
  .calculator-results {
    border-inline-start: 2px solid var(--color-ink);
  }
  /* במובייל (מתחת ל-980px) - מעבר לקו אופקי עליון */
  @media (max-width: 980px) {
    .calculator-results {
      border-inline-start: none;
      border-block-start: 2px solid var(--color-ink);
    }
  }
  ```
- **אנימציית קרוסלת הלוגואים:** המחלקה `.companies-marquee` המופעלת באמצעות `@keyframes marquee { 0% { transform: translateX(0); } 100% { transform: translateX(-50%); } }`.
- **כפתור העצירה:** כפתור ה-HTML `button[data-carousel-toggle]` המפעיל ומכבה את מחלקת העצירה `.is-paused` על מסילת הלוגואים, אשר משנה ב-CSS את מצב האנימציה ל-`animation-play-state: paused`.

### ג. עמוד "איך מתקבלים?" (how-to-be-accepted.html)

#### הסבר בעברית

עמוד זה מוקדש להכנה לתהליכי המיון ומציג מאגר פרויקטים לדוגמה וכן שאלות נפוצות מראיונות עבודה.

סינון הפרויקטים מתבצע באמצעות מערכת טאבים המחולקת לארבע קטגוריות. 16 הפרויקטים האמיתיים מוצגים בכרטיסיות מותאמות הכוללות כפתור הרחבה. בעת לחיצה על כפתור ההרחבה הירוק הזוהר, הכרטיסייה נפתחת כלפי מטה ומציגה תיאור מורחב וקישור פעיל לפרויקט בשרתי HIT. דאגנו שהמעבר הויזואלי יהיה רך ויוקרתי באמצעות פונקציית תזמון הדרגתית, ומנענו חיתוך של כפתור הקישור בתחתית בעזרת ביטול הסתרת התוכן העודף במצב פתוח.

שאלות הראיונות מעוצבות ככרטיסיות תלת-ממדיות מרהיבות המתהפכות ב-180 מעלות. בחלק הקדמי מופיעה השאלה (רקע לבן), ובעת ריחוף עכבר או פוקוס מקלדת הכרטיסייה מסתובבת ומציגה בגב שלה את התשובה המלאה והטיפים (על גבי רקע ורוד בוהק). פתרנו באג ויזואלי שבו הרקע צבע הכרטיס גלש מעבר לפינות המעוגלות על ידי הגדרת הגבולות ועיגול הפינות ישירות על גבי הפאות המסתובבות עצמן. מנגנון הסינון של השאלות שופר ב-JavaScript כך שיבצע סינון מדויק לפי מילות מפתח מוגדרות בלבד, ולא לפי טקסט חופשי, ובכך נשמר איזון של בדיוק שתי שאלות לכל קטגוריה.

#### שמות מחלקות ופרטים טכניים

- **טאבים וסינון פרויקטים:** המחלקה `.project-tabs` והכרטיסייה `.project-card`.
- **אזור התוכן המתרחב בפרויקט:** המחלקה `.project-more` וכפתור החץ `.project-toggle-icon`.
- **אנימציית פתיחה חלקה ב-CSS:**
  ```css
  .project-more {
    max-height: 0;
    overflow: hidden;
    transition: max-height 500ms cubic-bezier(0.25, 1, 0.5, 1);
  }
  .project-card.is-expanded .project-more {
    max-height: 12rem; /* מותאם לגובה התוכן */
    overflow: visible; /* מונע חיתוך כפתורים */
  }
  ```
- **כרטיסיות FAQ מתהפכות:** מכולת הכרטיס הכללית `.flip-card`, מכולת הסיבוב הפנימית `.flip-card-inner`, והפאות הפיזיות `.flip-card-front` ו-`.flip-card-back`.
- **אפקט הסיבוב ב-CSS:**
  ```css
  .flip-card {
    perspective: 1000px;
  }
  .flip-card-inner {
    transform-style: preserve-3d;
    transition: transform 0.6s cubic-bezier(0.4, 0, 0.2, 1);
  }
  .flip-card:hover .flip-card-inner,
  .flip-card:focus-within .flip-card-inner {
    transform: rotateY(180deg);
  }
  .flip-card-front,
  .flip-card-back {
    position: absolute;
    backface-visibility: hidden;
    border: 2px solid var(--color-ink);
    border-radius: 32px; /* עיגול פינות מוגדר ישירות על הפאות */
  }
  ```

### ד. עמוד "אודות" (about.html)

#### הסבר בעברית

עמוד זה מציג מידע על יוצרי האתר ומסגרת הקורס בפקולטה לטכנולוגיות למידה ב-HIT.

עיצבנו את הדף במבנה גריד שבו הכרטיסייה הראשית ("פותח על ידי") תופסת את כל רוחב הדף (מתפרסת על פני שתי עמודות). הכרטיסייה כוללת הסבר על מהות הקורס, קישור רשמי לאתר הפקולטה ולוגו רשמי ווקטורי של המוסד. פתרנו בעיית טשטוש בלוגו ה-SVG על ידי פירוק מבנה ה-defs/use הפנימי שלו והצגת התמונה ישירות, יחד עם קביעת יחס גובה-רוחב קשיח ב-CSS שמנע ממנו להימתח או לאבד מאיכותו ברזולוציות שונות.

#### שמות מחלקות ופרטים טכניים

- **גריד הדף:** המחלקה `.about-layout`.
- **כרטיסיית פותח על ידי (רוחב מלא):** המחלקה `.about-card.full-width` המקבלת ב-CSS את ההגדרה `grid-column: span 2`.
- **לוגו HIT המעוצב ב-CSS:**
  ```css
  .hit-card-logo {
    height: 48px;
    width: auto;
    aspect-ratio: 877 / 273; /* מונע עיוות מתיחה */
    object-fit: contain;
  }
  ```

### ה. עמוד "צור קשר" (contact.html)

#### הסבר בעברית

עמוד זה מיועד ליצירת קשר ומעוצב בפריסה דו-עמודתית רספונסיבית המשלבת כרטיסי מידע סטטיים מצד ימין וטופס פנייה מודרני מצד שמאל.

בטופס הוסר שדה מספר הטלפון כדי לקצר את תהליך הפנייה. כדי לשמור על גריד מאוזן ויזואלית, הגדרנו ששדה האימייל יתפרס לרוחב מלא (שתי עמודות בדסקטופ), בעוד ששמות הפרטי והמשפחה מופיעים זה לצד זה בשורה הראשונה. הטופס מונגש במלואו: תוויות הטקסט מקושרות באופן בלעדי לשדות הקלט, שדות החובה קיבלו סימון נגיש מותאם, וישנה תיבת חיווי סטטוס המעדכנת מיד קוראי מסך בעת הצלחה או שגיאה בשליחת הטופס.

#### שמות מחלקות ופרטים טכניים

- **פריסת הדף הכללית:** המחלקה `.contact-layout`.
- **כרטיסי המידע הסטטיים:** המחלקה `.info-card` (מעוצבים ללא אפקטי תזוזה בריחוף לשמירה על יציבות עיצובית).
- **גריד הטופס הפנימי:** המחלקה `.form-grid`.
- **שדה אימייל ברוחב מלא ב-CSS:**
  ```css
  .form-group.full-span {
    grid-column: span 2;
  }
  ```
- **מאפייני נגישות בטופס:** שימוש ב-`<label for="email">` מקושר ל-`<input id="email">`, הוספת המאפיין `aria-required="true"` לשדות חובה, והגדרת `role="status"` ו-`aria-live="polite"` על תיבת הודעת הסטטוס `#form-status`.

### ז. דף שגיאה 404 (404.html)

#### הסבר בעברית

דף שגיאה מותאם אישית המציג הודעה ברורה כאשר גולש מגיע לכתובת שאינה קיימת. הדף מעוצב בשפת האתר וכולל כפתור לחזרה מהירה לדף הבית וכפתור המפעיל היסטוריית דפדפן לאחור לחזרה לעמוד הקודם. דאגנו לקשר את קובץ ה-JS גם בדף זה לטובת שלמות הניווט.

  ```html
    חזרה לעמוד הקודם
  </button>
  ```

## 3. ארכיטקטורת נגישות מיוחדת: תפריטי הניווט (Accessible Dropdowns)

### הסבר בעברית

אחד האתגרים הגדולים ביותר בנגישות אתרים הוא הנגשת תפריטים נפתחים (Dropdowns) בראש האתר למשתמשי מקלדת. במקור, התפריטים "קריירה" ו"כלים שכדאי להכיר" נפתחו רק באמצעות ריחוף עכבר, דבר שמנע ממשתמשי מקלדת לגשת אליהם.

פיתחנו פתרון מקיף ויציב במיוחד בקובץ ה-JavaScript:

1. **טריגר מקלדת כפול:** כפתורי פתיחת התפריטים מגיבים כעת למקשי `Enter` ו-`Space`. לחיצה עליהם פותחת או סוגרת את התפריט ומעדכנת את הסטטוס לקוראי מסך.
2. **מעבר פוקוס אוטומטי:** בעת פתיחה במקלדת, הפוקוס מועבר אוטומטית ובאופן מיידי אל הפריט הראשון (או האחרון, אם נפתח עם חץ למעלה) בתוך התפריט הנפתח, מה שחוסך הקשות Tab מיותרות למשתמש.
3. **ניווט חצים מלא:** המשתמש יכול לנווט למעלה ולמטה בין אפשרויות התפריט בעזרת מקשי החצים במקלדת בצורה מחזורית חלקה (מהסוף להתחלה ולהיפך).
4. **סגירה מהירה (Escape):** לחיצה על מקש `Escape` בכל מקום בתפריט סוגרת אותו מיידית ומחזירה את הפוקוס בצורה תקינה לכפתור הראשי שפתח אותו.
5. **מעקב פוקוס גלובלי ללא השהיות (Focusin Document Listener):**
   במקום להשתמש באירוע `focusout` רגיל שלעיתים נסגר מוקדם מדי בגלל השהיות תנועת פוקוס בדפדפנים שונים (רייס קונדישן), הגדרנו מאזין גלובלי מסוג `focusin` ברמת ה-`document`. בכל פעם שמתבצע פוקוס על אלמנט חדש כלשהו באתר, הקוד בודק האם הוא נמצא בתוך תיבת הדרופדאון הפתוח. אם המשתמש יצא מהתפריט (למשל עבר עם Tab לפסקה הבאה או לקישור הבא) - התפריט נסגר מיד.

## 4. נקודות מפתח להצגה בפרזנטציה (Tips for Presentation)

במהלך ההצגה של הפרויקט מול בוחנים, מומלץ להדגיש את שלוש הנקודות הללו כדי להראות חשיבה מקצועית ומעמיקה:

1. **שימוש בשפה עיצובית אחידה (Neo-Brutalism):** הסבירי שבחרתם לעצב את האתר עם קווים שחורים עבים, צבעים נועזים וצלליות מוסטות קשיחות כדי לשדר ייחודיות ומודרניות, ושכל האלמנטים נשענים על משתני CSS גלובליים (CSS Variables) המבטיחים קוד נקי ותחזוקה קלה.
2. **נגישות כערך מוביל (Accessibility-First):** הדגימי לבוחנים כיצד ניתן לתפעל את כל האתר - כולל פתיחה וניווט בתפריט הראשי, מעבר בקומיקס ועצירת תנועת הלוגואים - **באמצעות המקלדת בלבד** (מקשי Tab, חצים, Enter ו-Escape), והסבירי שזהו סטנדרט חובה לאתרים מודרניים המשרתים את כלל האוכלוסייה.
3. **רספונסיביות חכמה (Responsiveness):** הראי כיצד רכיבים מורכבים (כמו מחשבון השכר וכרטיסיות השאלות) מגיבים בצורה מושלמת לשינויי גודל מסך בזכות שימוש נכון ב-CSS Grid ובשאילתות מדיה מאוחדות ועקביות.
